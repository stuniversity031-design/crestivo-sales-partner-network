# Crestivo Sales Partner Network V2

## Commission model
- **50% commission on every one-time service by default.**
- **30% recurring commission on monthly maintenance, support and subscriptions by default.**
- **Weekly payouts.**
- Both percentages are editable from **Admin → Program Settings** without touching source code.

## V2 additions
- Central commission settings
- Dynamic commission display throughout dashboard and partner preview
- One-time vs recurring service classification
- Editable service catalog
- No-code content editor
- Weekly commission center
- Partner management
- Partner-facing preview

## Run
npm install
npm run dev

This is the working application foundation. Before live launch, connect authentication, database, lead attribution, contracts, payment processing and real weekly payouts.
